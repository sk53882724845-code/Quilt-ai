QUILT AI — WEBSITE STARTER
==========================

This is a mobile-friendly, light-theme front-end starter for Quilt AI.

FILES
-----
index.html  Main page and interface
style.css   White/light responsive styling
app.js      Navigation and demo interactions

HOW TO USE
----------
1. Extract QuiltAI.zip.
2. Upload index.html, style.css, app.js, and README.txt to the same folder in your GitHub Pages repository.
3. Keep the filenames unchanged.
4. Open the published website.

IMPORTANT — AI MODEL CONNECTION
-------------------------------
This is the user interface, not a trained AI model. The current version does not actually generate AI images, audio, or model-powered chat responses. It prepares prompts and displays a clear notice.

To enable real generation, we must build/connect backend endpoints for:
- Chat model
- Text-to-image model
- Text-to-speech model

Do not put private API keys in app.js or any public GitHub Pages file. Keep secrets on a server/backend. Training an original model from scratch is a separate project and requires suitable datasets and computing resources.

DESIGN
------
Light theme, ChatGPT-inspired conversation layout, Quilt AI branding, image studio, voice studio, responsive mobile sidebar.
